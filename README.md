[Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)
bounty on make.fun.

## The entry

> My agent asked me to clarify my question, then clarified its clarification, then billed me for the meeting.

## How it works

`main.py` (Python 3 stdlib only, no network, no randomness) validates the line
(single line, 1–200 characters) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.

```sh
python3 main.py
```
